# goit-pycore-hw-08

Домашнє завдання до теми 12: серіалізація об'єктів. Бот-помічник із попередньої роботи тепер зберігає адресну книгу у файл за допомогою `pickle` і відновлює її під час наступного запуску, тож контакти не губляться після виходу.

## Структура

- `address_book.py` — класи `Field`, `Name`, `Phone`, `Birthday`, `Record` та `AddressBook` (без змін із hw-07)
- `bot.py` — консольний бот: функції `save_data` / `load_data`, обробники команд з декоратором `input_error`, функція `main`

## Запуск

Сторонні бібліотеки не потрібні, достатньо Python 3.

```
python bot.py
```

Під час запуску бот читає `addressbook.pkl` у поточній теці (якщо файлу ще немає, починає з порожньої книги), а під час виходу записує туди всі контакти. Книга зберігається за командами `close` / `exit`, а також якщо роботу перервано через Ctrl+C або Ctrl+D. Якщо файл порожній або пошкоджений, бот перейменовує його на `addressbook.pkl.bak` і починає з порожньої книги, щоб не затерти старі дані.

## Команди

- `add [ім'я] [телефон]` — додати контакт або ще один номер до наявного
- `change [ім'я] [старий телефон] [новий телефон]` — замінити номер
- `phone [ім'я]` — показати телефони контакту
- `all` — показати всі контакти
- `add-birthday [ім'я] [DD.MM.YYYY]` — додати день народження
- `show-birthday [ім'я]` — показати день народження
- `birthdays` — кого привітати протягом наступних 7 днів
- `hello` — привітання від бота
- `close` або `exit` — зберегти книгу і вийти
